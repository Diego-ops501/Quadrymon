# Quadrymon

![Quadrymon](quadrymon-logo.png)

Aplicativo para gerenciar ate quatro contas, consultar o mercado global e analisar hunts.

Desenvolvimento e manutencao: Diego-ops501.

## Executar

Instale as dependencias com `npm ci` e execute `npm start`. Use `npm test` para verificar a base e `npm run dist` para gerar o instalador Windows.

## Recursos

- Quatro contas com sessoes persistentes e recarga conjunta.
- Mercado global com filtros, sugestoes do catalogo e agrupamento de variantes.
- Navegacao entre mercado e hunt anterior.
- Inventario, IVs, alertas e resumo das contas.
- Recomendacoes por nivel, movimentos, dados de hunt e medicoes de combate.

O perfil local utiliza a pasta `pokemux` do usuario. As credenciais sao cifradas pelo sistema operacional e nao fazem parte deste repositorio.

A versao 2.2.0 ainda precisa de validacao de paridade em partidas reais. Atualizacoes automaticas ficam desativadas ate a primeira publicacao validada.
